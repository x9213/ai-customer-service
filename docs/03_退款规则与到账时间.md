# 退款规则与到账时间

适用范围：校园数码小店所有订单  
更新时间：2026-09-22  
关键词：退款、到账、原路退回、审核

## 1. 退款方式
- 退款原路退回，即用哪种方式支付，就退到哪种方式。
- 不支持退到其他账号。

## 2. 退款时间
- 客服审核：1-3个工作日。
- 财务处理：1-3个工作日。
- 到账时间：通常1-7个工作日，具体以银行或支付平台为准。

## 3. 退款条件
- 未发货订单：可全额退款。
- 已发货订单：需拒收或签收后申请退货。
- 退货退款：仓库验收通过后发起退款。

## 4. 异常情况
- 超过7个工作日未到账，请联系客服。
- 支付平台优惠券、积分抵扣部分，按平台规则退回。
- 涉及金额争议，转人工客服处理。

## 5. 必须转人工
- 退款金额不对
- 退款超过7个工作日未到账
- 用户要求加急
- 用户投诉
