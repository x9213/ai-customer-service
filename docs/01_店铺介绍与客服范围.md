# 店铺介绍与客服范围

适用范围：校园数码小店  
更新时间：2026-09-22  
关键词：客服范围、转人工、营业时间

## 1. 店铺介绍
校园数码小店面向在校学生，销售耳机、充电宝、数据线、键盘、鼠标、U盘、贴膜等数码配件。

## 2. 客服可处理
- 商品咨询：价格、参数、库存、适用设备
- 订单问题：修改地址、取消订单、发货时间
- 售后问题：退换货、退款、保修
- 物流问题：查询快递、延迟、丢件
- 发票：电子发票申请
- 会员：积分、优惠券

## 3. 客服不处理
- 价格谈判、索要赠品
- 投诉升级、法律纠纷
- 涉及隐私、账号密码、验证码
- 其他超出店铺范围的问题

## 4. 必须转人工
- 用户明确要求人工
- 投诉、差评、法律、媒体
- 涉及金额争议、退款异常
- 客服不确定或知识库没有答案
- 用户情绪激动、辱骂

## 5. 服务时间
人工客服：每天 9:00-21:00  
非工作时间：留言，次日回复。
