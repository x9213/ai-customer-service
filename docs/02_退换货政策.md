# 退换货政策

适用范围：校园数码小店所有商品  
更新时间：2026-09-22  
关键词：退货、换货、7天无理由、运费

## 1. 7天无理由退货
- 签收后7天内，商品未拆封、不影响二次销售，可申请无理由退货。
- 退货前需联系客服，提供订单号和退货原因。

## 2. 质量问题退换
- 签收后15天内出现非人为质量问题，可换货或退货。
- 需提供照片或视频证明。

## 3. 运费承担
- 无理由退货：买家承担运费。
- 质量问题：店铺承担运费。

## 4. 不支持退货的情况
- 已拆封的耳机、贴膜、定制商品。
- 人为损坏、进液、私自拆机。

## 5. 退货流程
1. 联系客服申请。
2. 客服审核。
3. 买家寄回。
4. 仓库验收。
5. 退款或换货。
