# 🎧 基于 RAG 的校园电商智能客服系统

## 📖 项目简介
本项目是一个面向校园数码小店的智能客服助手。基于大语言模型和 RAG（检索增强生成）技术，能够读取私有知识库文档，准确回答退换货、退款、物流等售后问题。支持流式对话、拒答转人工和安全防护。

## ✨ 核心功能
- **私有知识库问答**：基于本地 Markdown 文档，不依赖模型记忆。
- **精准引用**：回答基于检索到的文档片段，防止幻觉。
- **安全防护**：拒绝恶意注入攻击，拒绝索要隐私信息。
- **转人工机制**：知识库外问题自动引导转人工。
- **网页交互界面**：基于 Streamlit 的实时聊天窗口。

## 🛠️ 技术栈
- 编程语言：Python 3.10+
- 大模型框架：LangChain
- 模型 API：智谱 AI（glm-4-flash / embedding-3）
- 向量数据库：Chroma
- 前端界面：Streamlit

## 🚀 快速开始
1. 克隆项目：`git clone <你的仓库地址>`
2. 安装依赖：`pip install -r requirements.txt`
3. 修改 `src/app.py` 中的 `API_KEY` 为你的智谱 Key。
4. 运行：`streamlit run src/app.py`
